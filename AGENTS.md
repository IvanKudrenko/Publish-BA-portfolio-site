# Repository instructions

Before making any visual, UI, UX, layout, typography, spacing, color, image-treatment, animation, responsive, component-style, or navigation change, read `DESIGN.md` and `DESIGN_SYSTEM.md` first.

All visual work must comply with both documents. Do not introduce a pattern that violates them, and do not invent a new local design language for an individual page.

If a requested visual change conflicts with the established design system, preserve the system and ask Ivan before introducing the exception.

This is a non-negotiable repository rule.
